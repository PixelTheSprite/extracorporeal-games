# Legally Distinct Mix-Em-Up — Arcade Edition

Legally Distinct Mix-Em-Up is a fast-paced platform fighter with arcade-style mechanics and competitive gameplay. An original cast of fighters goes up against public-domain characters from books, folk tales and early comics.

Every earlier version is still playable from the Version menu in the game's top bar: v1 (released as HTML5 Scuffle), v2 (36 fighters and the first boss), v3 (the boss gallery and three new bosses) and v4, the current one (six bosses, Boss Rush and costumes).
